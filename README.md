# KiranaStore – Power BI Data Analytics Project

## 📊 Project Overview
KiranaStore is a Power BI data analytics project focused on retail business data analysis and visualization.

## 🎯 Project Objective
The objective of this project is to analyze store data and present useful business insights through an interactive Power BI dashboard.

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX

## 📁 Project File
The Power BI report file is available in this repository.

## 🚀 Project Demonstration
Download the `KiranaStor.pbix` file and open it using Microsoft Power BI Desktop to explore the dashboard and its visualizations.
